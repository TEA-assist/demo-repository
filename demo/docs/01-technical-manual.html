Technical Manual — TEA AI Product Finder

Complete technical reference for the live asktea.ai stack. Sources: product-graph-api/docs/, product-graph-web-ui/docs/, product-graph-ai-engine/docs/, product-graph-infra README, product-graph-mobile-app/docs/.

1. Architecture overview

Single-node Docker Swarm, 5 stacks sharing attachable overlay tea-infra-net: tea-infra (Postgres 16, Redis 7, RabbitMQ 4, MinIO, Qdrant v1.19, pgAdmin, RedisInsight), tea-monitor (Grafana, Loki, Promtail), tea-portainer (Portainer CE), tea-caddy (Caddy 2.11 Cloudflare DNS-01), tea-app (ai-engine + api + web-ui from GHCR :main).

2. Data plane

  • Postgres 16 (async SQLAlchemy + asyncpg, 32 ORM models, 35 migrations): 7,682 store_products, 67k+ images, product_embeddings (one row per product × per model, id md5(product_id:model)), embed_models catalog (9 seeded: Qwen3-0.6B/4B/8B, F2LLM-v2-4B, jina-v5-text-small, BGE-M3, Nomic v2, e5-base/large), llm_models/llm_api_keys (Fernet-encrypted) /llm_settings/prompt_templates/system_settings/ai_description_versions, search_eval_queries/judgments, activity_logs, stores/members, catalog taxonomy.
  • Qdrant v1.19: per-model collections products-qwen3-embedding-4b (dims from model name: 0.6B→1024, 4B→2560, 8B→4096), point id uuid5(product_id_lang) — one point per language (en + ar), dense + BM25 sparse text_bm25 indexed, flat filters _color/_material/_category/_brand/_gender/_color_family/_size.
  • Mongo Atlas: chat conversations/messages (optional → 503 when absent). MinIO 4 buckets: product-graph, temp-files, profile-photos, store-photos. Redis 7: response cache, rate-limit INCR Lua, distributed cron locks. RabbitMQ: search_requests / web_scrape_jobs / search_results (search consumer removed).
  • Bootstrap: engine always asks the API on startup (idempotent, backoff 5s→60s ×12) — no skip-if-file-exists.

3. API (FastAPI)

Unified envelope APIResponse[T], typed domain exceptions (never raw HTTPException), every raise carries translation_key mapped in web-ui messages/{en,ar,fa}.json. Auth: phone OTP + Google OAuth, JWT access+refresh with jti rotation and reuse detection, httpOnly cookies + CSRF for browsers, Bearer for native, RBAC admin/seller.

  • Admin (/api/v1/admin/, get_admin_user): LLM models/keys/settings (6 endpoints), prompt templates, system settings, cron products, embedding cron (list/detail/active-model/reindex), ai-engine embed-text test, search-eval (generate/import/list/update/judgments/metrics/search).
  • Stores/products: store CRUD (max 3 per owner) + members (owner/manager), product CRUD with images/variants/color-sets, GET /stores/my/products (light ProductListItem 16 fields, ?q= fuzzy), GET /stores/my/products/stats ({total,active} counts), public GET /stores/{id}/products/{pid} (rate-limited 120/min, no auth — chat product view), GET /public/products/random (Redis 1h), GET /product-info/{id}/{lang} (UUID→name resolution, minified for prompts).
  • Chat: WS /ws/chat/{id} (subprotocol token for anon, cookie for logged-in), POST /chat/anonymous-session (ephemeral 10-min WS-only token), REST + streaming frames.
  • Other: files (MinIO upload), health/ready/metrics (Prometheus), webhooks (/webhook/embedding-result {product_id,lang,status,model}), 862 tests ~75% coverage, mypy strict, ruff clean.

4. AI Engine (stateless)

  • LLM: DeepSeek V4 Flash via OpenCode Zen (OpenRouter for overrides); two clients — default (descriptions/parsing) + conversational (chat/tools/summaries/titles); DB-backed encrypted keys with env fallback; runtime refresh via POST /config.
  • Chat (POST /chat): locale detect (fa>ar>en) → intent router (greeting/search/general) → tool-calling search_products first (parallel specs merged/deduped), parse fallback second (rewritten_query + filters + raw-query dual spec), direct answers skip search. Per spec: embed query (Qwen3 instruct prefix) → Qdrant filtered search + color-only tier + unfiltered fallback, size-bonus re-rank, model-aware thresholds (1024:0.3 / 2560:0.25), hybrid dense+sparse Fusion(RRF) pool ×3 cap 100 with stopwords/stemming/name-boost, language-aware dedupe (prefer_lang), color safety-net filter injection. SSE frames: debug → assistant_start → product_cards → text_chunk* → assistant_end / error. Pre-flight advisory pings (TTL cache, 2s→6s) never block — real calls arbitrate.
  • Embedding (POST /embed-product): embed monolingual passage per language → upsert uuid5(product_id_lang) with dense + BM25 sparse → webhook (3 attempts) → API marks product_embeddings done/error. Embed text: per-language structured text (name/category/is_search_affecting attributes + price-tier/season/occasion tokens), concrete fields first; filters aliased/normalized (printed→Multicolor, gender map, size canonical, one-size fallback).
  • Other: /generate-description (bilingual JSON, temp 0.7), /summarize (rolling S2), /title (2–6 words), /similar (category→color-family→unfiltered tiers, dense-only), /eval/queries + /eval/search (deterministic parse-path with per-hit scores), /embed-text (admin vector test), /transcribe (STT). 533 tests ~90%+.

5. Seller-list search (exact algorithm)

WHERE (name ILIKE '%phrase%' ← exact substring, both languages
       OR per-token trigram: name % 'token')   — both langs
ORDER BY (exact-phrase bonus 1.0
          + Σ greatest(similarity(name_en,tok), similarity(name_ar,tok))) DESC

Shared helper _name_match_and_score(q) in product-graph-api/app/repositories/product_definition.py. Typo-tolerant, multi-word aware ("RAFFIA BRAIDED VISOR" ranks exact first, then partials). <3 chars → substring fallback. Store scope AND-ed.

6. Web UI (Next.js 16, React 19)

  • Public (website) group outside auth guard: home hero + AnonymousChatBox (anon session → WS, full-screen Sheet, useCloseOnBack) + RandomProductsSection (Swiper 1→3→5, autoplay with visibility pause) + ProductViewDialog (self-fetching detail). About at /about.
  • Dashboard guard + locale prefix always (/en|/ar|/fa, default ar, RTL). Admin 11 nav items, seller 4 nav items, Switch View persists tea_preferred_view. RTK Query only (cookie + X-Requested-With, single refresh retry), Zod-validated responses, 370 Vitest tests + Playwright e2e.
  • Chat: useChat state machine + useChatSocket transport (subprotocol token, 30s ping, backoff ≤30s, 4001 terminal), intent-themed bubbles, similar chips → similar_request, debug dialog, copy button.
  • Seller product wizard order (src/components/product/steps/): BasicInfo → Description (short_description_en ≥20) → N attribute groups (multi-piece → CompositeColorSetsEditor) → PriceInventory (VariantGridEditor cartesian) → Media (≥3 images, alt_text_en, inline payload) → Review → redirect to Generate Description (model selector = models-with-active-keys only, auto-run, collapsed prompt + Run Edited Prompt, history restore).

  • Shopping: home feed (light lists) → ProductViewModal (self-fetch detail, gallery fallback, favorite toggle) → chat drawer (wss://…/ws/chat/{id}?token=JWT, ping/backoff, idempotency_key similar turns) → favorites/profile (avatar via envelope pattern).

8. Search evaluation

Golden set scripts/seed_data/search_eval_golden.json ({"description","queries":[...]}, 166 queries 124en/42ar): paste inner queries array (page tolerates wrapper object too) into admin Import → 166 rows. Judge dialog auto-runs search limit:20 → toggle relevant → Save/Skip. Metrics MRR@10/Recall@10 (overall + EN/AR, cached 300s). Generate path builds bilingual catalog context (types + is_search_affecting attributes + major options) and calls engine /eval/queries.

9. CI/CD & deployment

All 4 app repos run on [self-hosted, tea-server] runners. Quality gates (lint + format + typecheck + tests) → build (retry ×3, cache) → migrate → deploy (flock serialized, stack deploy --detach=false + force-update ×5, git_sha baked into /health). Infra repo: validate (compose config + caddy validate + shellcheck/yamllint/actionlint) → rsync → optional Ansible → rewrite server .env (16 vars) → scripts/deploy.sh (infra→monitor→portainer→caddy→app). Backups: Postgres dumps + Mongo mongodump→MinIO cron + Qdrant snapshots (see dev-tools/ and infra docs/backups.md).

10. Security checklist

  • JWT rotation + reuse revocation, OTP 10-min + bypass only when TWILIO_BYPASS=true, Fernet-encrypted LLM keys (prod refuses to start without LLM_ENCRYPTION_KEY), per-route Redis rate limits + login lockout, PII redaction in logs, activity logs (DB + JSONL, 60-day retention).
  • Open: Loki unauthenticated, Qdrant host-published, engine API-key guard disabled (overlay trust only), mobile APKs debug-signed, iOS Google Sign-In blocked on URL scheme. Each has a documented remediation in the source docs.
