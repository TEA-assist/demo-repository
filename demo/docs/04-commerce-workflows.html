Status language

These labels distinguish documented behavior from demos, product-owner reports, and real-provider launch readiness. A configuration screen or connector is not proof of a live commercial service.

  • Implemented
  • Simulated
  • Reported Implemented
  • Awaiting Credentials
  • Awaiting Verification
  • Planned
  • Live Verified

Current launch boundary

Mock payment and the demo carrier support repeatable demonstrations only. Live payment, provider accounts, carrier route validation, payout rails, finance/legal approvals, and store-specific verification remain launch gates. This page does not mark any external commerce provider as Live Verified without explicit evidence.
