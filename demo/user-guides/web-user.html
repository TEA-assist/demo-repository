Shopper Guide (Web) — app.asktea.ai

No account needed to start. The public home is outside the auth guard: hero + anonymous AI chat + random-products slider + about page. Login (phone OTP or Google) unlocks favorites and profile.

1. Anonymous browsing (no login)

  1. Open https://app.asktea.ai/ar (or /en).
  2. See the hero, then the chat box (AnonymousChatBox): collapsed composer → tap to expand → full-screen Sheet (back button closes via useCloseOnBack).
  3. Type naturally — black evening dress, gold ring, حذاء رياضي. The assistant streams text + product cards. Session is ephemeral (10-min WS-only token, no account).
  4. Browse the Random Products slider (RandomProductsSection: Swiper 1→3→5 columns by breakpoint, autoplay pauses when tab hidden). Click any card → ProductViewDialog fetches full detail.
  5. Visit /about for the store story.

2. Login

  1. Tap Login → Phone OTP (6 digits) or Google Sign-In.
  2. Web auth is httpOnly-cookie (credentials: "include" + X-Requested-With: XMLHttpRequest) — no Bearer token in storage. Refresh is automatic; failure logs you out.
  3. After login, product links carry store context, and Favorites + Profile appear in nav.

3. Shopping with AI chat

  1. From the home Sheet (or /[locale]/admin/product-search if staff), type what you want in your own words.
  2. Streaming shows text_chunk + product_cards. Cards open the full view (ProductGrid 2→4 columns, theme-aware).
  3. Tap a similar-product chip to fire a similar_request turn ("find more like this").
  4. Tap the heart on any product to favorite it (login required).

4. Language

Every URL carries a locale prefix (/ar, /en). Switch via the header language popover. Arabic is default with full RTL; search works in both languages including typos.

5. Common issues

SymptomWhat to do
No results for a searchRephrase (seller search is fuzzy-ranked; if still empty the seller hasn't added products for that store)
Chat looks stuckRetry the turn (same idempotency key — no duplicate) or open a new chat
Favorites missingLog in — anonymous sessions don't keep favorites
Wrong languageHeader popover → pick AR/EN (URL prefix changes)
