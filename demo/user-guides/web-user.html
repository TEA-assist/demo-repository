Shopper — app.asktea.ai & Website Home

Anonymous browsing

app.asktea.ai home is the public (website) group outside the auth guard: hero, AnonymousChatBox (log in prompt → collapsed composer → full-screen Sheet via useCloseOnBack), RandomProductsSection (Swiper slider, 1→3→5 breakpoints, autoplay with visibilitychange pause), ProductViewDialog self-fetching detail. About page at /about.

Login

  • Phone OTP (OTP autofill badge disabled) or Google Sign-In. Web auth is httpOnly-cookie (credentials: "include" + X-Requested-With: XMLHttpRequest), no Bearer in storage.
  • After login, product detail links carry store context; favorites and profile become available.

Shopping & chat

From the home Sheet or /[locale]/admin/product-search when given access, type natural queries ("black evening dress", "running shoes"). Streaming shows text_chunk + product_cards; similar-product chips trigger another similar_request turn. Product cards open the full view with theme-aware ProductGrid (2→4 columns).

Common issues

  • No results for a shopper list search → seller search is now fuzzy-ranked; if still empty, the seller hasn't created products for that store.
  • Language: URL carries locale prefix (/ar, /en). Switch via header language popover.
