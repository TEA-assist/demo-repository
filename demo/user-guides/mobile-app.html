Shopper Guide (Mobile) — React Native 0.86

Native shopper app: browse the feed, chat with AI, view products, manage favorites and profile. Three flavors — dev / staging / production (com.tea.app[.dev]). Backend: API_BASE_URL=https://app-dev.asktea.ai/api/v1 via Cloudflare Tunnel.

1. Install

  • Android: take the CI artifact TEA-dev.apk for your flavor (job android-build in ci.yml: manual, branch→flavor). Today's builds are debug-signed (no keystore.properties → debug keystore fallback — see product-graph-mobile-app/docs/release-and-signing.md). Install on device, accept unknown-source prompt.
  • iOS: scaffold only — run pod install first (no Podfile.lock/workspace committed). Google Sign-In on iOS is blocked until a URL scheme is added.

2. Onboarding (first run)

  1. Open the app → Phone screen: pick country (combobox) + type local number → submitted as {dialCode}{localNumber}. Or tap Continue with Google.
  2. OTP screen: enter the 6-digit code (InputOTP). On Android the SMS User Consent native module captures the inbound SMS automatically (hint flicker fixed in b0d2821; regex matches code|otp|كود|رمز|کد per locale). Dev bypass 1234 when TWILIO_BYPASS=true.
  3. Permissions: grant Location when-in-use and Notifications to enable chat/product features.

3. Shopping

  • Home feed — product cards from light ProductListItem lists. Tap a card → ProductViewModal (self-fetching detail via useGetStoreProductQuery, gallery image fallback, favorite toggle).
  • Chat drawer — open the drawer, type naturally. Transport wss://…/ws/chat/{id}?token=JWT with ping/backoff and queued frames. Similar products fire a new turn with idempotency_key (safe retry, no duplicates).
  • Favorites / Profile — heart to save, remove dialog to unsave; profile avatar upload uses the envelope.ts pattern ({success,data}).

4. Language & errors

  • App i18n: react-i18next, locales en/ar/fa. Every label exists in all 3 files; user-facing errors come from the error namespace via showError(error) toasts (never raw English).
  • If chat fails: the turn shows retry — tap it (same key). If images fail: RetryingThumbnail re-fetches automatically.

5. Known gaps (stated honestly for stakeholders)

  • No OTA updates, deep linking, or push-notification infra (permission checks only).
  • Detox e2e is scaffolding — detox missing from deps, binary paths predate flavors, iOS workspace absent.
  • Single patch patches/@maplibre+maplibre-react-native+11.3.6.patch ships with Log.i("TEA-MapTouch") debug logging — scheduled cleanup.
