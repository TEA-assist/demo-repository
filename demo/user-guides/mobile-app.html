Mobile Shopper — React Native 0.86

Install

  • Android: CI artifact TEA-dev.apk per flavor (dev/staging/production) from ci.yml's android-build job (manual, main/staging/develop, branch→flavor). Today debug-signed (keystore.properties missing → falls back to debug keystore — see product-graph-mobile-app/docs/release-and-signing.md).
  • iOS: scaffold present, no Podfile.lock/workspace committed — run pod install first; Google Sign-In on iOS is blocked until a URL scheme is added.

Onboarding

  1. Open the app → Phone screen (country combobox + local input → {dialCode}{localNumber}) or Continue with Google.
  2. OTP screen — 6-digit InputOTP; on Android the SMS User Consent native module captures the inbound SMS automatically (hint flicker fix landed in b0d2821; regex matches code|otp|كود|رمز|کد per locale).
  3. Permissions → Location when-in-use, notifications — grant to enable chat/product features.

Shopping

  • Home — product feed via light ProductListItem lists; product tap → ProductViewModal (self-fetching detail via useGetStoreProductQuery, gallery image fallback, favorite toggle).
  • Chat drawer — WS wss://…/ws/chat/{id}?token=JWT with ping/backoff; similar products trigger a new turn with idempotency_key.
  • Favorites / Profile — favorite remove dialog, profile avatar upload via envelope.ts pattern.

Known gaps

  • No OTA updates, deep linking, or push-notification infra (permission checks only).
  • Detox e2e is scaffolding — detox missing from deps, binary paths predate flavors, iOS workspace absent.
  • Single patch patches/@maplibre+maplibre-react-native+11.3.6.patch ships with Log.i("TEA-MapTouch") debug logging — scheduled cleanup.
