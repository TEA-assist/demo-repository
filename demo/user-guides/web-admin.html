Portal · User Guides — Admin

Admin — dash.asktea.ai

Role admin (log in with the prod admin — dev admin restored to production). All pages live under /[locale]/admin/..., locale prefix is always (every URL starts with /en or /ar). i18n: ar default, RTL. Admin view is chosen via sidebar Switch to Seller (persists tea_preferred_view).

Login

  • Phone → OTP (code valid 10 min, check backend logs for dev code; bypass 1234 when TWILIO_BYPASS=true), or Google Sign-In (code exchange via redirect_uri, one-time state). On failure, switch view stays on admin — sellers only see 4 nav items.
  • Middleware: src/proxy.ts locale negotiation; dashboard layout guards unauthenticated → /login, non-admin on /admin* → /seller.

Dashboard (/admin)

7 gradient tiles: Catalog Data · AI Chat · Cron Jobs · Conversations · LLM · Prompts · System + Scrapers (added af0c657).

Catalog Data (/admin/data)

Product type selector → category tree → attribute groups → is_search_affecting chip. Read-only browser; seller products are the live catalog.

AI Chat (/admin/product-search)

RAG search: sidebar conversations (via GET /chats), new chat creates conversation with create_new, WS wss://…/ws/chat/{id} with subprotocol token (no ?token=), streaming text_chunk/product_cards, DebugDialog shows trace, similar-product chips. See useChat + useChatSocket.

Cron Reports (/admin/cron + /llm-product-description + /embeding-product)

Status filters (All/Pending/Generated or per-model), detail dialog with prompt + en/ar, Re-index (destructive, AlertDialog confirm), Embedding cron shows per-model detail rows.

Conversations (/admin/chats)

Admin reads user chats + feedback — title + anonymous badge columns (added ffdff26), message history via GET /admin/chats/{id}/messages. No purge endpoint exists.

Search Evaluation (/admin/search-eval)

Generate (LLM, 1–50, EN/AR checkboxes), Import (paste the inner array jq '.queries' scripts/seed_data/search_eval_golden.json — page now tolerates the wrapper object after the search-eval import fix; still prefer the bare array), table (locale/source/status/q + pagination), judge dialog (auto-runs search limit:20 → toggle relevant → Save Judgments / Skip), metric cards MRR@10+Recall@10 (overall + EN/AR, cached 300s).

Settings

  • LLM (/admin/settings/llm) — provider→model groups, add/delete/toggle API keys (PATCH /:keyId/toggle), set default model (only models with active keys appear as options).
  • Prompts — 6 editors (pre_prompt, ending_prompt, chat_assistant, parse_query, summarize, title).
  • System — toggle product_ai_generation_cron.
  • AI Engine — provider/tunnel config + embedding test card (full vector + copy).
  • Scrapers (/admin/settings/scrapers) — header status badges (error/ready), raw-header textarea draft, Save (PUT), Clear (DELETE) with confirm. Tag ScraperHeaders.
