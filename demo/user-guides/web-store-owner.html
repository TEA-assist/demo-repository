Store Owner Guide — asktea.ai → /seller

For sellers who own stores and their catalog. Admins: use sidebar Switch to Seller to see this view. Seller nav has exactly 4 items: Dashboard · Stores · Products · Profile. Store edit pages live at /seller/stores/[id]/edit (no nav entry). Only owners manage members.

1. Login & role

  1. Open https://asktea.ai and log in with phone OTP or Google.
  2. Sellers land on /seller (stats: total/active via GET /stores/my/products/stats — fast counts, no product rows).
  3. Admins: sidebar → Switch to Seller. Refresh once so the role cache (tea_preferred_view) settles.

2. Stores — create, edit, team

  1. Go to Stores → New store (max 3 per owner).
  2. Fill name, description, phone, logo (PhotoUploader with crop), address + map location, website/Instagram, country + currency, hours via WorkingHoursEditor. Save.
  3. Open the store → scroll to Team (StoreMembersSection). Owners add members by phone or email with role owner/manager (POST /stores/{id}/members); remove non-owners with the row delete (DELETE /stores/{id}/members/{member_id}); list anytime (GET /stores/{id}/members).

3. Products — list & search

  • Open Products. Cards are light (ProductListItem, 16 fields — no variants/descriptions payload) so the list stays fast.
  • Search with ?q= — now fuzzy-ranked: try RAFFIA BRAIDED VISOR. The exact name ranks first, then partial-word products. Typo-tolerant in both languages; under 3 chars it falls back to substring.
  • Click a card → ProductViewDialog → ProductView self-fetches the full detail. Gallery fallback: color-matched → unlinked → all images.

4. Products — 6-step wizard (in order, src/components/product/steps/)

  1. BasicInfo — trilingual names, SKU, brand, category.
  2. Description — short_description_en required (≥20 chars).
  3. N × Attribute groups — fill each group. Multi-piece products (is_multi_piece) swap the color-pattern step for CompositeColorSetsEditor (pieces/color_sets, piece↔color validation).
  4. Price & Inventory — hosts VariantGridEditor (client-side cartesian in cartesianAttr useMemo). Set prices + quantities per variant.
  5. Media — upload ≥3 images via ProductImageUploader (immediate POST /files/upload, alt_text_en required, crop-and-reupload supported — payload built inline by lib/product-form.ts buildImagePayload).
  6. Review — validation rules (required/min_length/…/max_select) are checked. Save → you are redirected to Generate Description.

5. Generate Description (/seller/stores/[id]/products/[productId]/generate-description)

  1. The page auto-runs on entry with the default model. The model dropdown lists only models with active API keys.
  2. Preview the en/ar results. To iterate: expand the collapsed prompt, edit it, press Run Edited Prompt.
  3. Open History to compare versions and Restore any of them. Results write ai_description_en/ar.
  4. On error: retry or skip — the product stays saved, descriptions can be generated later, and the 300s background cron also fills pending products.
