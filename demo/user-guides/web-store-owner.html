Portal · User Guides — Store Owner

Store Owner — dash.asktea.ai → /seller

Login & role

Phone OTP or Google; admin users switch to Seller via sidebar Switch to Seller. Seller nav has 4 items: Dashboard · Stores · Products · Profile. Store edits exist at /seller/stores/[id]/edit (not a nav entry) and only owners can manage members.

Stores

  • Create/edit a store: name, description, phone, logo (PhotoUploader, crop), location, hours via WorkingHoursEditor.
  • Team: StoreMembersSection — list members with role badges, AddMemberDialog by phone/email (role owner/manager), MemberRow delete — owners can remove non-owner members. APIs: GET /stores/{id}/members, POST/DELETE /stores/{id}/members.

Products wizard

Order (verify in src/components/product/steps/):

  1. BasicInfo — names (trilingual), SKU, brand, category
  2. Description — short_description_en required (≥20 chars)
  3. N × Attribute groups — multi-piece products swap color-pattern for CompositeColorSetsEditor (is_multi_piece, pieces/color_sets, piece_id↔color_option_id validation)
  4. Price & Inventory — hosts VariantGridEditor (client-side cartesian in cartesianAttr useMemo)
  5. Media — ≥3 images via ProductImageUploader, immediate upload to POST /files/upload, alt_text_en required, crop-and-reupload supported — payload sent inline via lib/product-form.ts buildImagePayload
  6. Review — validation_rules (required/min_length/… max_select), post-submit redirects to Generate Description.

Lists show light cards (ProductListItem, 16 fields): GET /stores/my/products (search via ?q=, now fuzzy-ranked). Card click → ProductViewDialog → ProductView self-fetches full detail; gallery fallback: color-matched → unlinked → all images.

Generate Description (/seller/stores/[id]/products/[productId]/generate-description)

Model selector shows only models with active API keys, auto-generates on entry, collapsed prompt + Run Edited Prompt, history dialog with restore, retry/skip on error. Results write ai_description_en/ar.
