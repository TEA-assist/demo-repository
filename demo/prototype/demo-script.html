1 — Admin (5 min)

  1. Login as admin on dash.asktea.ai → Dashboard shows 7 tiles (Catalog Data, AI Chat, Cron Jobs, Conversations, LLM, Prompts, System + Scrapers).
  2. Catalog Data → browse product types → categories → attribute groups — point out multi-piece flag.
  3. AI Chat (/admin/product-search) → send "black evening dress" → show streaming text_chunk + product_cards, debug dialog.
  4. Search Evaluation → metric cards (MRR@10 / Recall@10, overall + EN/AR). To load data: jq '.queries' ~/Projects/TEA-assist/product-graph-api/scripts/seed_data/search_eval_golden.json | pbcopy → paste bare array into Import → 166 rows.
  5. Settings: LLM (models with active keys), Prompts (6 editors), AI Engine (embedding provider 4B + vector test), Scrapers (header status badges).

2 — Store Owner (4 min)

  1. Switch View → Seller (or login as seller) → Seller dashboard shows stats (total/active via GET /stores/my/products/stats).
  2. Stores → create/edit a store (name, phone, hours via WorkingHoursEditor).
  3. Products → list is light (ProductListItem, 16 fields) — search RAFFIA BRAIDED VISOR → exact name first, then partials (fuzzy ranking live). Open a card → ProductView gallery (color-matched → unlinked fallback).
  4. Product form: walk BasicInfo → Description (en required) → N attribute groups → PriceInventory (VariantGridEditor, client-side cartesian) → Media (≥3 images, alt_text_en) → Review → Save → redirect to Generate Description.
  5. Generate Description → pick a model (only models-with-active-keys listed) → Run → preview en/ar → History restore.

3 — Shopper, web (2 min)

  1. Open app.asktea.ai logged-out → home hero + AnonymousChatBox: type "gold ring" → full-screen Sheet → chat → similar-product chips.
  2. Login via phone OTP (or Google — now baked into prod images after ac5a262 CI fix) → favorites appear.

4 — Shopper, mobile (2 min)

  1. Install the flavor APK (TEA-dev.apk from CI artifacts; debug-signed — see repo docs/release-and-signing.md). iOS: pod install → run (iOS scaffold not buildable without Podfile.lock/workspace — note).
  2. Onboarding: phone → OTP (bypass 1234 when TWILIO_BYPASS=true) → permissions (location when-in-use, notifications).
  3. Home → ChatDrawer → similar products → ProductViewModal (RetryingThumbnail) → favorite toggle.
