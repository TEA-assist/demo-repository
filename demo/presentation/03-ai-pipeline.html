03 — AI Pipeline

Hybrid search — seller lists + RAG chat

Seller lists (/stores/my/products?q=) use a shared helper _name_match_and_score(q) in product-graph-api/app/repositories/product_definition.py:

WHERE (name ILIKE '%phrase%' ← exact substring, both languages
       OR per-token trigram: name % 'token')   — both langs
ORDER BY (exact-phrase bonus 1.0
          + Σ greatest(similarity(name_en,tok), similarity(name_ar,tok))) DESC

Typo-tolerant, multi-word aware: "RAFFIA BRAIDED VISOR" ranks exact name first, then partial-word products. <3 chars → plain substring fallback. Store scope is AND-ed (fixed in this session where it leaked into the OR).

RAG chat (POST /ws/chat/{id}): pre-flight advisory pings (TTL cache, 2s→6s retries), intent router (greeting/search/general → error), tool-calling parse, filter normalization, hybrid dense+BM25 search in Qdrant (FusionQuery(RRF), pool ×3 cap 100, thresholds 1024:0.3 / 2560:0.25, size-bonus tier), then streaming frames assistant_start → text_chunk → product_cards → assistant_end (log trace: SEARCH_SIZE_TIER, DIRECT_ANSWER…). Never blocked by pings — real call is arbiter.

Descriptions & embeddings

  • Descriptions: per-store LLM (OpenCode Zen / OpenRouter), 6 prompt templates, bilingual JSON, history dialog — generated via POST /stores/{id}/products/{pid}/generate-descriptions.
  • Embeddings: monolingual passages from minified product JSON (nulls stripped, images→alt_texts), uploaded to Qdrant with filters (_color, _material …) plus text_bm25 sparse.
  • Search evaluation: golden set scripts/seed_data/search_eval_golden.json (`{"description", "queries": [...]}` — paste the inner queries array into the admin page), metrics MRR@10 / Recall@10 cached 300s, judge dialog auto-runs with limit:20.
