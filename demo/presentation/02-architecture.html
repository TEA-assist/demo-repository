Hardening note (from product-graph-infra/docs/security.md): published ports bypass UFW via Docker iptables — qdrant:6333 and loki:3100 are internet-reachable today. Remediation options: remove host publishing / loopback bind / DOCKER-USER chain / Cloudflare Access.

Data plane

  • Transactional: Postgres 16 (7,682 store_products, 11k+ embeddings rows) + Mongo Atlas (chat conversations/messages, optional → 503 when absent)
  • Semantic: Qdrant per-model collections products-qwen3-embedding-4b — point id = uuid5(product_id_lang), dense+BM25 sparse indexed
  • Object storage: MinIO 4 buckets — product-graph, temp-files, profile-photos, store-photos
  • Cache/rate-limit: Redis (response cache, rate Limit/INCR Lua, distributed cron locks)
  • Bootstrap: Engine always asks the API on startup (idempotent, backoff 5s→60s ×12) — no skip-if-file-exists.

CI / deploy

All 4 app/api/web-ui/ai-engine repos run on [self-hosted, tea-server] runners. Quality gates → build (retry ×3, cache) → migrate → deploy (flock serialized, stack deploy --detach=false + force-update ×5, git_sha baked into /health).
