# Demo Repository System Overview

Documentation and demo portal for the TEA-assist platform. This repo does not run application code; it hosts stakeholder documentation, presentation decks, demo scripts, and role-based user guides.

## Contents

- `demo/docs/` — full documentation and technical manual (HTML).
- `demo/presentation/` — executive/architecture/AI pipeline/investor decks.
- `demo/prototype/demo-script.html` — live click-path demo script.
- `demo/user-guides/` — admin, store owner, shopper web, shopper mobile guides.
- `index.html` — portal entry point.

App `https://app.asktea.ai` · Dashboard `https://asktea.ai` · API health `https://app.asktea.ai/api/v1/health`.
